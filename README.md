# Student Performance Prediction — Assignment 1

## Model
Linear Regression

## Target
`exam_score`

## Numeric Features
age, study_hours_per_day, social_media_hours, netflix_hours, attendance_percentage, sleep_hours, exercise_frequency, mental_health_rating

80% training, 20% testing, `random_state=42`

- R² Score: 0.8989
